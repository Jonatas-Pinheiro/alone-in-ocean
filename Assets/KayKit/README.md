# KayKit — assets integrados

Este diretório contém somente arquivos das versões gratuitas dos packs KayKit aprovados. Os arquivos originais de licença de cada pack estão preservados nas pastas correspondentes; todos indicam Creative Commons Zero (CC0). Não é necessário atribuir crédito, mas os créditos e as fontes ficam registrados aqui.

## Packs e uso no jogo

- [KayKit Adventurers](https://kaylousberg.itch.io/kaykit-adventurers) — seis personagens GLB rigados, usados como visuais dos jogadores. O personagem é escolhido de forma estável pelo ID multiplayer; o visual local continua oculto para manter a câmera em primeira pessoa.
- [KayKit Character Animations](https://kaylousberg.itch.io/kaykit-character-animations) — animações Rig_Medium para idle, caminhada, corrida, pulo, coleta e uso de itens. A locomoção acompanha o movimento replicado; gestos de coleta/consumo são disparados pelo servidor.
- [KayKit RPG Tools Bits](https://kaylousberg.itch.io/rpg-tools-bits) — modelos GLTF usados nos pickups existentes: machado para madeira, corda para plástico, martelo para sucata, faca para alimento e balde para água.

Foram mantidos os formatos GLB/glTF e seus arquivos de dependência necessários no Godot. Os níveis pagos EXTRA/SOURCE, arquivos editáveis `.blend` e formatos redundantes não foram incluídos.
